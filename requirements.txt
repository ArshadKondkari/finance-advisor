# Saarthi requirements manifest
#
# IMPORTANT:
# Saarthi is a React/TypeScript + Node.js project, not a Python project.
# Do not install this file with "pip install -r requirements.txt".
# The actual JavaScript install command is "corepack pnpm install".
#
# Runtime requirements
# --------------------
# Node.js 20.19+ or Node.js 22+
# pnpm 9+
# PostgreSQL 14+
#
# The exact transitive versions are pinned in pnpm-lock.yaml.
# Direct package dependencies are declared in these package manifests:
# - package.json
# - artifacts/api-server/package.json
# - artifacts/finance-advisor/package.json
# - lib/db/package.json
# - lib/api-spec/package.json
# - lib/api-zod/package.json
# - lib/api-client-react/package.json
#
